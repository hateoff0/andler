# andler-net

Network configuration for virtual machine instances. Provides bridge, isolated, and NAT network setup for QEMU virtual machines.

## Current State

Implemented. Contains `NetworkService` trait and `DefaultNetworkService` implementation for host-side network configuration.

## Features

- **Bridge mode**: Attach VM to an existing Linux bridge on the host.
- **Isolated mode**: Create a completely isolated network environment with no external connectivity.
- **NAT mode**: Provide NAT-based network access with configurable backend (Slirp or Passt).

## How It Works

The `DefaultNetworkService` uses the `ip` command (from iproute2) and `nft` (nftables) to configure network interfaces:

- **Bridge setup**: Creates a TAP interface, adds it to the specified bridge, and brings both up.
- **Bridge teardown**: Removes the TAP interface from the bridge. The bridge itself is intentionally left UP — it may be shared with other VMs or host network. Only the TAP interface is removed.
- **Isolated setup**: Creates a TAP interface, brings it up, and adds nftables rules to allow established/related connections and drop all other incoming traffic.
- **Isolated teardown**: Removes the nftables rules and destroys the TAP interface.

**nftables rationale:** Isolated mode uses nftables to provide stronger isolation than merely disabling IP forwarding. The rules explicitly drop all incoming traffic from the VM while allowing established/related return traffic, preventing the VM from accidentally contacting the host or other VMs even if IP forwarding were later enabled.

## QEMU Integration

`andler-qemu` integrates the network service:

- Before spawning QEMU, the appropriate network setup is performed.
- After stopping QEMU, the network teardown is performed.

The QEMU command-line arguments are generated by `cmdline::network_args`:

- Bridge mode: `-netdev tap,id=net0,ifname=tap{ID},bridge={bridge},script=no,downscript=no -device virtio-net-pci,netdev=net0`
- Isolated mode: `-netdev tap,id=net0,ifname=andler0,script=no,downscript=no -device virtio-net-pci,netdev=net0`
- NAT mode (Slirp): `-netdev user,id=net0 -device virtio-net-pci,netdev=net0`
- NAT mode (Passt): `-netdev passt,id=net0 -device virtio-net-pci,netdev=net0`

## Dependencies

- `andler-core` for `NetworkConfig` and `NetworkMode` types.
- `tokio` for async command execution.
- `thiserror` for error handling.
