# andler-net

Network configuration for virtual machine instances. Provides bridge and isolated network setup for QEMU virtual machines.

## Current State

Implemented. Contains `NetworkService` trait and `DefaultNetworkService` implementation for host-side network configuration.

## Features

- **Bridge mode**: Attach VM to an existing Linux bridge on the host.
- **Isolated mode**: Create a completely isolated network environment with no external connectivity.

## How It Works

The `DefaultNetworkService` uses the `ip` command (from iproute2) to configure network interfaces:

- **Bridge setup**: Creates a TAP interface, adds it to the specified bridge, and brings both up.
- **Bridge teardown**: Removes the TAP interface from the bridge and brings interfaces down.
- **Isolated setup**: Creates a veth pair, brings both up, and configures an isolated network on the host side.
- **Isolated teardown**: Destroys the veth pair.

## QEMU Integration

`andler-qemu` integrates the network service:

- Before spawning QEMU, the appropriate network setup is performed.
- After stopping QEMU, the network teardown is performed.

The QEMU command-line arguments are generated by `cmdline::network_args`:

- Bridge mode: `-netdev tap,id=net0,ifname=tap{ID},bridge={bridge},script=no,downscript=no -device virtio-net-pci,netdev=net0`
- Isolated mode: `-netdev tap,id=net0,ifname=andler0,script=no,downscript=no -device virtio-net-pci,netdev=net0`

## Dependencies

- `andler-core` for `NetworkConfig` and `NetworkMode` types.
- `tokio` for async command execution.
- `thiserror` for error handling.

## Future Work

- nftables/iptables rule management for advanced isolation.
