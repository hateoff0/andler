# andler-store

Персистентное хранилище состояния инстансов на SQLite.

## Что здесь есть / будет

- `migrations/` — миграции схемы.
- `src/lib.rs` — репозиторий для CRUD над `InstanceConfig`/состоянием FSM
  (`andler-core::fsm`), используемый `andler-daemon` для восстановления списка
  инстансов после перезапуска демона.

## Важно

Этот крейт не хранит бизнес-логику переходов состояний — только персистентность
того, что уже решено в `andler-core`. Валидация и переходы FSM остаются в
`andler-core`/`andler-daemon`.
