# andler-net

Структуры конфигурации сети для инстансов (NAT, мосты, nftables-правила).

## Статус

Ранняя стадия — на момент написания содержит только структуры конфигурации,
без реальной настройки интерфейсов хоста. Логика применения сетевых настроек
появится вместе с `andler-qemu` (сеть подключается флагами QEMU) и, при
необходимости, отдельным слоем работы с `nftables` на хосте.
